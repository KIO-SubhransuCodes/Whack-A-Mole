🔨 Whack-A-Mole! (Web Edition)

An interactive, fast-paced arcade game built completely from scratch using the classic web trifecta: **HTML5, CSS3, and Vanilla JavaScript**. Test your reflexes and see how many moles you can whack before the timer runs out!

🎮 How to Play

1. Click the **"Start Game"** button to kick off the countdown.
2. Moles will randomly pop up from their holes and disappear quickly.
3. **Click (Whack!)** the moles to score points.
4. Try to get the highest score possible before the time limit hits zero!

---

🚀 Key Features

* **Dynamic Gameplay:** Random mole generation with unpredictable timing to keep players on their toes.
* **Real-Time Scoring:** Responsive score tracking that updates instantly with every successful whack.
* **Smooth Animations:** Clean CSS transitions and keyframes that handle the rising and hiding of the moles seamlessly.
* **Responsive Design:** Styled to be playable across different screen sizes.

---

🛠️ Tech Stack & Implementation

* **HTML5:** Structured the game board, holes, moles, scoreboards, and control buttons.
* **CSS3:** Handled the visual styling (giving it that classic arcade feel), layout positioning, and smooth animations using custom transitions.
* **JavaScript (ES6):** The brain of the game. Managed the game state, randomized mole logic, event listeners for whacking, score counting, and the game clock countdown.

---

💡 What I Learned (Great for Portfolios!)

> Building this project helped me master asynchronous JavaScript concepts like `setTimeout` and `setInterval` for managing game loops and timers. It also deepened my understanding of DOM manipulation, event handling, and managing state without external libraries.
